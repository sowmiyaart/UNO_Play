# 🃏 UNO Play

A browser-based UNO card game built using **HTML, CSS, and JavaScript**.

The game is designed for **desktop gameplay**, where one human player competes against three computer-controlled players.

## 🎮 About the Game

UNO Play is a web-based implementation of the classic UNO card game. The game supports a **4-player setup**, with **1 human player and 3 computer players**.

The project was built from scratch using vanilla web technologies, with a focus on game logic, interactive UI, card handling, and player turns.

## ✨ Features

* 👤 **1 Human Player vs 3 Computer Players**
* 🃏 Interactive UNO card gameplay
* 🎴 Card drawing
* ⏭️ Skip cards
* 🔄 Reverse cards
* ➕2 cards
* 🎨 Color change / Wild cards
* ➕4 Wild cards
* 🏆 Automatic game progression and winner detection
* 🎴 Card visuals implemented using a **sprite sheet**
* 💻 Designed for **desktop view**

## 🛠️ Technologies Used

* **HTML5** — Structure and game interface
* **CSS3** — Styling, layout, and card presentation
* **JavaScript** — Game logic, player turns, card actions, and interactions

## 🧩 Technical Highlight

The UNO cards are represented using a **sprite sheet**, allowing the game to display different card faces while keeping the card assets organized and efficiently managed.

## ▶️ How to Play

1. Open the deployed game in a desktop browser.
2. The game starts with one human player and three computer players.
3. Play cards according to the rules of UNO.
4. Use special cards such as **Skip, Reverse, +2, Wild, and +4** strategically.
5. Draw a card when you cannot make a valid move.
6. Continue playing until a player wins the game.

## 💻 Platform

**Desktop browsers**

> ⚠️ This project is currently designed for desktop screens and is not optimized for mobile or other screen sizes.
